# Memory — Base de Conocimiento del Proyecto

Esta carpeta es la memoria persistente del proyecto.
Se actualiza con cada sesión para no repetir errores y mantener contexto.

## Archivos

| Archivo | Contenido |
|---|---|
| `negocio.md` | Info de Diego, su negocio, clientes activos, stack técnico |
| `errores_aprendidos.md` | Todos los errores encontrados y sus fixes definitivos |
| `clientes.md` | Clientes activos, demos, pipeline de prospectos, proceso de onboarding |

## Cómo usar esta carpeta

Al inicio de cada sesión, leer estos archivos para:
1. Saber qué errores NO cometer
2. Conocer el contexto del negocio
3. Saber en qué estado están los clientes

Al final de cada sesión, actualizar con:
- Nuevos errores encontrados y sus soluciones
- Cambios en el estado de clientes
- Nueva información del negocio
